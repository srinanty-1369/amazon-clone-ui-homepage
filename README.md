# Amazon Homepage UI 🛒

A static Amazon homepage UI created using HTML and CSS as part of my frontend development practice.

## 🌟 Features

- Navigation bar with Amazon-style layout
- Search bar UI
- Location and account sections
- Hero banner section
- Product category cards
- Multi-section footer
- CSS Flexbox layouts
- Hover effects and styling

## 🛠️ Technologies Used

- HTML
- CSS
- Font Awesome

## 📚 What I Learned

- HTML page structure
- CSS selectors and properties
- Flexbox and alignment
- Background images
- Box model
- Margins and padding
- Hover effects
- Creating layouts using HTML and CSS

## ⚠️ Project Status

This is a static frontend practice project.

- Only the homepage UI is implemented.
- Navigation links and page redirections are not functional.
- No JavaScript or backend functionality is implemented.
